# 📜 AutoLog
###   A mod that saves all chat messages to a custom.html file

### 🌐 Features

* Saves all messages sent in Chat to an index.html file inside .minecraft

### 🔴 Utility

> With AutoLog You will have on your computer, the entire log of your departure, so if you need to review a message, or review a name or anything like that sent via chat, you can, in a simple way

### 📁 Folder

> The messages are saved inside a folder in your.minecraft called Historic
